# Kichta Run

Un mini-jeu de course inspiré des runners hors connexion : aide Kichta à sauter par-dessus les obstacles.

- Compatible téléphone et ordinateur
- Commandes tactiles, souris et clavier
- Difficulté progressive et record local
- Fonctionne hors connexion après la première visite
