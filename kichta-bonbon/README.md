# Kichta Run Bonbon

La version « bonbon » de Kichta Run : une course à trois couloirs dans un monde de confiseries.

- **Commandes** : ◀ ▲ ▶ (balayage du doigt, vers le bas pour glisser), double saut.
- **Mondes** : 7 mondes (dont 3 à acheter).
- **Gameplay** : blocs « ? », bonus, wagons, Pucci en boss.
- **Récompenses** : missions et niveaux qui débloquent des chapeaux, coffres, cadeau secret.
- **Boutique** : vintage, pelages, mondes.

Jouer : https://massiyousfi23-source.github.io/Snake-Massi/kichta-bonbon/
Sur iPhone : ouvrir le lien dans Safari → Partager → « Sur l'écran d'accueil ».
Sur Android : l'APK est fabriqué automatiquement (voir `android/` et l'onglet Releases du dépôt).

Mode test : ajouter `?debug` à l'adresse.
